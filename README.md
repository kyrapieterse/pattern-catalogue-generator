# Pattern catalogue generator

Turn a folder of SVGs into a searchable offline catalogue with printable pattern swatches. This free browser tool works offline and processes files on your device.

## Run locally

Download the repository as a ZIP, extract it and open `index.html` in a modern browser. No build step, account or API key is required.

## Try the example

The example contains three swatches. Search for SC-002, print the filtered swatch, then clear the search and download the HTML catalogue. Open the downloaded file offline and search again. Use the folder picker to replace the samples with your own SVG collection.

## How it works

The generator keeps filenames as design codes and recognises optional names such as SC-001-diamond.svg. Each SVG is embedded as an image in the exported HTML. The downloaded catalogue includes its own search, styling and print layout. Use the SVG files you have permission to distribute.

For related examples and project guidance, see the [Tint & Screen screen pattern library](https://tintandscreen.co.za/architectural-screens/patterns/).
